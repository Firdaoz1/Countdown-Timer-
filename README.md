
# Countdown-Timer-

A simple and countdown clock built with HTML, CSS, and JavaScript. The application allows to set acountdown and displays the remaining time in real time.

# Features

- Set acountdown timer
- Display remaining minutes and seconds
- Start, pause, and reset functionality
- Clean and simple user interface

# Techmologies Used

- HTML
- CSS
- JavaScript
